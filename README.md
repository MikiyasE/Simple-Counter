# Simple Counter

A beginner-friendly interactive counter web app built with HTML, CSS, and JavaScript.

## What I Learned
- DOM manipulation
- Event listeners (click events)
- Updating content dynamically
- Basic project structure and clean code

## Features
- Increment counter
- Decrement counter
- Reset counter
- Clean and simple user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript 

## How to Run
1. Clone the repository
2. Open `index.html` in any browser

## Project Purpose
This is my first public project. I built it to practice fundamental JavaScript concepts and start building a portfolio for software engineering scholarships and future opportunities.
